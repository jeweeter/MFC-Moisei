## Что это

Справочная система для специалиста в окне приёма документов. Оператор задаёт
вопрос так, как думает — «загран ребёнку», «скок стоит выписка егрн», «прописка» —
и получает ответ **со ссылкой на конкретный раздел конкретной услуги** из базы
знаний mfc71.ru.

Ключевой принцип: **ассистент не имеет права выдумывать**. Он отвечает только по
найденным фрагментам базы знаний, каждое утверждение снабжает ссылкой на источник,
а если ответа в базе нет — так и говорит.

### Возможности

| | |
|---|---|
| 🔎 **Поиск, понимающий оператора** | Сокращения (СНИЛС, ЕГРН, ВБД), просторечия («прописка», «маткапитал», «детские»), опечатки, латинская раскладка (`ghjgbcrf` → «прописка»). Интерфейс показывает, *как* понят запрос |
| 💬 **Чат с Моисеем** | Круглая кнопка слева снизу открывает панель справа. Ответ стримится, каждая цифра — с кликабельной сноской на источник |
| 🧭 **Мастер по жизненной ситуации** | Вместо поиска по названию — пошаговый опрос («родился ребёнок» → «нужна регистрация» → «нужны выплаты») с выдачей **пакета связанных услуг** и сведённым чек-листом документов на весь пакет |
| ✅ **Чек-лист приёма** | Перечень документов — интерактивный список с отметками и копированием, прогресс сохраняется |
| ⚡ **Кэш ответов** | Ключ — пара «услуга + нормализованный вопрос». Повторный вопрос не идёт в API: экономия денег и времени, с подсчётом того и другого |
| 📊 **Качество данных** | Отчёт о полноте базы прямо в интерфейсе: где дозаполнять и чему не доверять |
| 🌓 **Светлая и тёмная темы** | Фирменные цвета МФЦ: красный, тёмно-коричневый, бежевый, чёрный, белый |

### Как это работает

```
запрос → понимание (раскладка, морфология, сокращения, опечатки)
       → гибридный поиск (BM25 по леммам + символьные n-граммы + BM25 по названиям, RRF)
       → кэш по паре (услуга, вопрос)
       → Claude отвечает ТОЛЬКО по найденным фрагментам, со ссылками [n]
         (без ключа API — автономный режим: выдержки из базы без генерации)
       → ответ + источники: услуга → раздел → оригинальный текст
```

Подробное обоснование выбора — в **[docs/SOLUTION.md](docs/SOLUTION.md)**.

### Качество поиска

Измерено на 39 реальных формулировках оператора (`backend/tests/eval_queries.json`):

| Recall@1 | Recall@3 | Recall@5 | Recall@10 | MRR | Медиана | p95 |
|---|---|---|---|---|---|---|
| 71.8% | 87.2% | **97.4%** | 100% | 0.812 | **13 мс** | 29 мс |

## 🚀 Запуск

### Что нужно

* **Python 3.11+**
* **Node.js 18+**
* Ключ Anthropic API — **необязателен**. Без него система работает в автономном
  режиме: поиск и мастер функционируют полностью, ассистент отвечает выдержками
  из базы без генерации.

### Вариант 1. Одной командой

```bash
git clone https://github.com/jeweeter/MFC-Moisei.git
cd MFC-Moisei
./run.sh
```

Скрипт создаст виртуальное окружение, установит зависимости, соберёт поисковый
индекс и фронтенд, поднимет сервер на **http://localhost:8000**.

### Вариант 2. По шагам

```bash
# 1. Бэкенд
python3 -m venv .venv
source .venv/bin/activate                 # Windows: .venv\Scripts\activate
pip install -r backend/requirements.txt

# 2. Индекс базы знаний (~6 секунд; собирается и сам при первом старте)
cd backend && python -m app.ingest.build_index && cd ..

# 3. Фронтенд
cd frontend && npm install && npm run build && cd ..

# 4. Сервер
cd backend && python -m uvicorn app.main:app --port 8000
```

Открыть **http://localhost:8000**

### Режим разработки (hot reload)

Два терминала:

```bash
# терминал 1 — API
cd backend && ../.venv/bin/python -m uvicorn app.main:app --reload --port 8000

# терминал 2 — фронтенд с горячей перезагрузкой
cd frontend && npm run dev
```

Открыть **http://localhost:5173** (запросы к `/api` проксируются на `:8000`).

### Включить полный режим с LLM

```bash
cp .env.example .env
# вписать ключ:  ANTHROPIC_API_KEY=sk-ant-...
```

Перезапустить сервер. В левой нижней части экрана индикатор сменится с
«Автономный режим» на «LLM · claude-sonnet-5».

### Проверка

```bash
cd backend
../.venv/bin/python -m pytest tests/ -q      # 42 теста
../.venv/bin/python -m tests.eval_search     # метрики качества поиска
```

### Обновить базу знаний

Положить новые `db_knowledge.json` и `flat_classification.json` в `data/raw/`
и перезапустить сервер — индекс пересоберётся автоматически (изменение исходных
файлов отслеживается по хешу). Отчёт о качестве новых данных:

```bash
./.venv/bin/python scripts/analyze_data.py   # перезапишет docs/DATA_ANALYSIS.md
```

## Стек и почему он

| Слой | Технология | Обоснование |
|---|---|---|
| Поиск | Свой BM25 (scipy sparse) + `char_wb` TF-IDF (scikit-learn) + RRF | Работает локально, без сервиса эмбеддингов — внедряемо в закрытом контуре МФЦ |
| Морфология | `pymorphy3` | Русский язык без тяжёлых моделей; лемматизация с кэшем |
| Опечатки | `rapidfuzz` | Быстрое расстояние Левенштейна по словарю корпуса |
| Очистка HTML | `beautifulsoup4` + `lxml` | Word-разметка требует разбора дерева, регулярками не лечится |
| API | FastAPI + SSE | Стриминг ответа ассистента, автодокументация на `/docs` |
| LLM | Anthropic Claude (`claude-sonnet-5`) | Строгое следование инструкции «только по контексту» |
| Кэш | SQLite (WAL) | Ноль инфраструктуры, переживает перезапуск |
| Фронтенд | React 18 + TypeScript + Vite | Без UI-фреймворка: дизайн-система в цветах МФЦ пишется точнее вручную |

## API

Документация Swagger — на `http://localhost:8000/docs`.

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/search?q=` | Поиск услуг с разбором запроса |
| `GET` | `/api/services/{id}` | Карточка услуги |
| `GET` | `/api/services/{id}/raw/{section}` | Оригинальный текст поля из выгрузки |
| `POST` | `/api/ask` | Вопрос ассистенту (RAG) |
| `GET` | `/api/ask/stream` | То же, потоком (SSE) |
| `GET` | `/api/wizard/scenarios` | Сценарии жизненных ситуаций |
| `POST` | `/api/wizard/package` | Подбор пакета услуг по ответам |
| `GET` | `/api/cache/stats` | Статистика кэша и экономии |
| `GET` | `/api/quality` | Отчёт о качестве базы знаний |
